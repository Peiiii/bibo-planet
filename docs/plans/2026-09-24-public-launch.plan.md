## 方向与约束

- 独立项目、独立前端；不是 NextClaw 私人助手的皮肤。复用公开 `@nextclaw/harness` 的 Agent 运行能力，世界身份、记忆、能量和账号归本项目。
- 不写死主人、好感度、阵营或剧情；同一精灵可受所有访客影响，但访客对话原文不默认公开。
- 用户允许访问已登录的 GitHub、Cloudflare、阿里云和模型账户，允许创建所需资源与密钥；凭据不得写入仓库、输出或对话。预算谨慎，避免无上限的推理账单。
- 模型不限 DeepSeek，优先复用本机 NextClaw 已配置且实际可用的供应商。`codex-sub` 的 GPT 能力值得保留作内部开发/验证，但不能把个人订阅代理当成公开访客的产品 API；公网应使用适合第三方应用的正式 API。
- 部署位置服从模型链路：若依赖境外模型，使用境外节点；若使用国内 DeepSeek 等可达服务，可评估国内计算节点，但域名、可达性和合规性必须另证。
- 已有阿里云实例承载其他服务，不得覆盖或重启无关服务；先只读评估资源与部署隔离。Cloudflare 已登录，可评估 HTTPS 入口。

## 上下文压缩后的恢复锚点

- **真正目标**：交付可直接获客的线上成品，而不是代码、原型、MVP 截图或仅能打开的网页。用户要求自己设定目标，持续推进到三次独立审查都认为可直接给真实用户使用；最终必须给公开访问链接。
- **产品本质**：一颗独特、真实、开放的 AI 精灵星球；多名访客遇见的是同一批精灵，精灵默认不属于任何人。先追求有趣，不把普通个人 Agent 的效率叙事套进来。精灵有共享经历、私人会话边界和真实模型能量；初始能力刻意简单，但产品不能显得粗糙。未来自扩展/mini-app 是方向，不可冒充首版已有功能。
- **执行授权**：用户明确授权使用已登录 GitHub、Cloudflare、阿里云和现有模型配置，授权创建所需资源、密钥、提交、推送与部署。仍必须保护凭据、不输出密钥、不影响同机现有服务、不开放无界模型消耗。个人 Codex/ChatGPT 订阅不作为第三方用户的公开推理 API。
- **独立性与复用**：这是隔壁独立项目、独立前端；仅复用 NextClaw 稳定 SDK/Harness 和可共享开发经验，不改成 NextClaw 私人助手的多用户皮肤。公开版暂不向精灵提供宿主文件/命令/网络工具；等真正执行隔离后再开放自改造。
- **当前真相**：公网页面、匿名 API、注册登录、三只精灵各自连续两轮真实回复、墨里两账号共享、退出重登、服务重启持久性已在公网 API 证实，代码在 GitHub；最近相遇信号和移动端引导修正已发布，但没有浏览器验收。每日加密本地+离机备份的同一服务已手动实跑并取回解密，发布前再次执行成功。模型失败的无伪造/无扣额行为有隔离集成测试，非公网故障实测。真实浏览器操作、首个自然定时触发和三轮产品审查仍未完成。任何后续接手者先复验线上状态，再执行剩余序列，不从头重建已完成部署，也不要把“已上线”改写成“可用已验收”。
